# 命令行待办清单 

使用 Python 3 在项目目录运行 `python main.py`。仅使用标准库，无需安装依赖。

## 操作说明

- 启动时自动展示待办。
- `1` 新增：输入 `标题，内容，分类`，分类可省略。使用中文逗号，标题和内容中不能包含中文逗号。输入 `exit` 返回菜单。
- `2` 修改状态：选择任务编号，再选择待完成或已完成。
- `3` 删除：选择任务编号。
- `4` 保存并退出。
- `5` 修改标题：选择任务编号，再输入非空标题。

例如输入 `学习 Python，练习类与对象，学习`，即可在“学习”分类中新增任务。

## 对照学习

- `Task.py`：单条任务的属性、标记完成、恢复待完成、修改标题，以及字典与对象转换。
- `TodoList.py`：按分类管理多个 Task 对象，新增、删除和组织保存、读取。
- `storage.py`：处理 JSON 文件读写，保留原有实现。
- `main.py`：收集输入、展示结果、调用对象方法并处理错误。

数据流：用户输入 → Task 对象 → TodoList 集合 → 字典 → JSON 文件。再次启动时，从 JSON 读取字典，再创建 Task 对象。

原有注释保留，关键变化使用 `【新增】`、`【改进】` 标注。原 Taskadd 中的集合管理逻辑及注释移到了 TodoList.add；初始化方法原注释中的默认分类名称也由 TodoList.add 生成。`@classmethod` 表示方法接收类本身（cls），因此可以直接调用 Task.from_dict 或 TodoList.load 来创建对象。

## 保存与异常

数据保存在项目内的 `data/todos.json`，兼容原有字段格式，首次运行自动初始化。每次操作后保存，退出前再次保存。

保存失败时，修改仍在内存中；排除权限或磁盘问题后再次保存，成功后再退出。强制关闭会丢失尚未保存的修改。读取到损坏 JSON 或无效任务数据时会提示并停止启动，避免覆盖原文件。此练习不支持多个进程同时修改数据。

运行验证：`python -B -m unittest -v`。测试使用临时目录，不会修改已有待办数据。
